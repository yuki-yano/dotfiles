# Test Pruning

コードベース内の全テストを精査し、積極的に削除・統合できるテストをすべてリストアップする。
判断の中心は「このテストを削除すると、どんな現実的な不具合を見逃すか」。
念のためという理由で残さず、実行時間・不安定さ・修正負担と保証の価値を比較する。
テスト件数やカバレッジの維持自体を目的にしない。

## 対象と作業範囲

- 対象の指定がなければコードベース全体を調べる。指定があれば、その範囲内の全テストを対象にする。
- 成果物は根拠付きの候補一覧。列挙・監査の依頼だけでテストや実装を変更しない。削除・統合の実装も依頼されている場合は、その指示に従う。

## 調べ方

1. テスト設定、実行スクリプト、CI、ファイル探索から対象を洗い出す。ファイル名だけに頼らず、ソース内テスト、パラメータ化されたケース、snapshot、skipされたテストも含めて把握する。
2. 全テストの本文と、判断に必要な対象実装・仕様を読む。テストが実際に通る経路、assertion、モックの境界を確認する。名前や行数だけで判定しない。
3. 各テストが検出する現実的な不具合を具体化し、他テストや型・ライブラリの保証と突き合わせる。重複はファイルやテスト階層をまたいで探す。
4. 以下の観点で候補を抽出し、まとめて削除・統合した場合にも、残す保証と統合先が成立するか確認する。

| 観点 | 削除・統合の判断 |
|---|---|
| 実装のコピー | 期待値側でも本体と同じ分岐・計算を再現し、同じ誤りが両方を通過する。独立した仕様上の期待値を検証しているかを確認する。 |
| モックの自己検証 | モックに設定した戻り値や、テスト自身が行った呼び出しだけを確認する。本体の判断や外部との契約を検証するモック利用とは区別する。 |
| 型・ライブラリの保証の再確認 | 型検査や依存ライブラリが保証済みの性質だけを再確認する。自前の設定・接続・変換や、型の保証が及ばない実行時入力の検証は別に評価する。 |
| 他テストとの重複 | 同じ条件・観測結果・不具合を別テストでも検出できる。似たassertionでも、通る経路や環境が異なれば固有の保証がないか確認する。 |
| 内部実装への過度な依存 | privateな状態、補助関数、呼び出し順・回数など、公開挙動が正しくてもリファクタリングで壊れる条件だけを固定している。その順序や回数自体が契約なら残す価値を評価する。 |
| 過剰なケース分け | 同じ同値クラスの入力を多数並べ、固有の不具合を検出しない。境界値、異常系、意味の異なる分岐を残して代表ケースへ絞れるか確認する。 |

## 判断の詰め方

- 不具合は「回帰するかもしれない」ではなく、起こり得る変更・入力と、誤って観測される挙動で説明する。根拠なく未知の不具合を想像して残さない。
- 独自に検出できる現実的な不具合がなく、保証の価値を説明できなければ削除候補にする。調査不足で判断できないものは未確認として、足りない証拠を示す。
- テストの一部だけが冗長なら、有効なassertionやケースを残す統合・縮小案にする。置き換えが必要な候補は、単純削除できる候補と区別する。
- 重複グループごとに残すテスト、取り込むassertion・ケースを指定する。候補同士を互いの代替根拠にして、まとめて消すと保証がなくなる一覧にしない。
- 残すテストは保証の範囲に加え、実行時間、不安定さ、失敗時の原因の分かりやすさ、修正負担で選ぶ。単体・結合・E2Eなどの階層だけで機械的に決めない。
- 実行時間や不安定さは既存の測定・実行履歴があれば根拠にする。未測定ならその旨を示し、コードからの推定と実測を区別する。判断に必要な場合だけ対象を絞って検証し、監査のために一律で全テストを実行しない。

## 出力

最初に対象範囲と調査状況を示す。調査済みのファイル・テスト群、除外範囲、未確認範囲を区別し、未読がある状態で全テストを精査済みとは報告しない。

候補を次の形式で、削除・統合の効果が高く根拠が明確な順にすべて挙げる。上位数件で打ち切らない。同じ理由でまとめる場合も、該当テストを特定できるようにする。

| 対象（file:line・テスト名） | 提案（削除・統合・縮小） | 該当観点と根拠 | 削除すると見逃す現実的な不具合 | 残すテスト・統合先・実施条件 | コストと保証の比較 |
|---|---|---|---|---|---|

固有の不具合がなければ、保証済みの箇所を示すか、何を検証していないため価値がないのか説明する。統合先は参照箇所と残す内容を示す。

候補一覧の後に、削除対象に見えたが固有の保証があるため残す主なテストと理由、未確認事項を簡潔に示す。候補がなければ、根拠とともにそう報告し、件数を作らない。
