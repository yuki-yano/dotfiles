# 診断項目

適用中のスタイル方針に関係する項目を調べ、場所と修正方針を記録する。解除した項目は既存の設計を基準にし、以下と異なるだけでは問題としない。表の修正案も、機能・情報の保持と日本語の可読性に従う。

## 面と配色

| 兆候 | 修正の方向 |
| --- | --- |
| 背景、カード、ボタン、選択状態すべてに紫〜青などのグラデーション | 中立色の面と、意味のある場所だけのアクセント |
| 見出し、数値、ロゴのグラデーション文字 | 主文字色の単色 |
| `shadow-[0_0_20px_rgba(139,92,246,0.5)]`などの発光や色付きの影 | 面の明度差、細い罫線、小さな中立色の影 |
| 背景の光の塊、ぼかした球体、強い色の枠線 | 内容を読める静かな背景と罫線 |
| 似た文字色が多数あり、役割が判別できない | 主・副・補助の3役 |
| すべてが強調され、優先順位がない | 主操作と内容の見せ場へ強調を集める |
| ガラス調カードの内側の白い光と色付きの影が重なる | 過剰な装飾を減らす。階層やプラットフォームに必要な素材表現は保つ |

## 書体

| 兆候 | 修正の方向 |
| --- | --- |
| 800〜900の太さを多用した見出し | 400〜500中心にしてサイズと色で主従を作る |
| `NAVIGATION`など、広い字間の全大文字ラベル | 通常の大文字小文字と字間。正式な略語は保持 |
| サイズと太さが多すぎる | 少数のスケールと役割へ整理 |
| 同種の数値で精度や桁揃えがばらつく | 意味を保った書式統一と`tabular-nums` |
| 小さい文字の負の字間、和文見出しの詰めすぎ | 字間と行間を戻し、実際の和文で確認 |
| 斜体だけに頼った強調 | 色や太さで表現 |

## アイコン

| 兆候 | 修正の方向 |
| --- | --- |
| ナビゲーションや見出しの装飾用絵文字 | 一つの線画セットか無装飾。コンテンツの絵文字は保持 |
| 件数の横に毎回絵文字が付く | 数値と必要なラベルだけ |
| アイコンのサイズ、線幅、色が不統一 | 役割に合う同じ枠、サイズ、線幅、色 |
| アイコンがずれてラベルの開始位置も揺れる | アイコンとラベルをそれぞれ同じ列へ |
| AI機能すべてに光やスパークルが付く | 機能の区別に必要な表示だけ残す |

## 余白

| 兆候 | 修正の方向 |
| --- | --- |
| `mt-[13px]`や`ml-[7px]`など、役割のない端数 | 既存スケールか4px刻み。光学補正は維持 |
| 同じリスト内の行高や間隔がばらつく | 同じ役割へ同じ値 |
| グループ内より別グループの方が近い | 内側を狭く、グループ間を広く |
| 並んだカードの内側余白が不統一 | 共通の余白 |
| セクションの片側だけが極端に空く | ページ全体で間隔を調整 |

## 文言と日本語

| 兆候 | 修正の方向 |
| --- | --- |
| 「おかえりなさい！」が主見出し | ページ名、対象期間、作業の文脈 |
| 「+12%!!」など、比較対象がない変化 | 「前月比+12%」など、基準を明記 |
| 「何でも検索してみましょう」などの長いラベル | 対象が必要なら「履歴を検索」、明らかなら「検索」 |
| 「可能性を解き放つ」など、内容を説明しない誇張 | 実際の機能・操作・結果 |
| 根拠がない利用者数や倍率 | 創作せず未確認として報告 |
| 長い日本語ラベルや文字拡大でボタンが欠ける | コンポーネントの幅と折り返しを調整 |
| 本文の文字単位の強制分断、句読点の不自然な改行 | 和文の禁則と意味のまとまりに沿う折り返し |

## 部品とチャート

| 兆候 | 修正の方向 |
| --- | --- |
| 件数、プラン、状態すべてが発光するpill | 静かな文字、必要な状態表示、キー表示 |
| 意味のない`New ✨`などのbadge | 不要なら削除。契約・利用条件・状態は保持 |
| 入力、ボタン、カードがすべて同じ丸い形 | 大きさと入れ子に合う角丸 |
| 一つの系列が虹色、棒が発光する | 系列や比較の意味が分かる色と静かな目盛り |
| すべてのチャートが同じ大きさ・同じ強調 | 主役のチャートと、異なる大きさや種類の補助表示 |
| すべてのstat cardに穴埋めの小グラフ | ラベル・数値・比較対象付きの変化。判断に必要な小グラフは保持 |
| 別のデータのように見える装飾的な反射や複製 | 実データと意味が対応する描画 |
| ロゴが光る球体やグラデーションのタイル | ブランドの変更範囲を確認し、許可された場合に単純化 |

## LPと画像

| 兆候 | 修正の方向 |
| --- | --- |
| 製品名を変えるだけで他製品にも使える見出し | この製品の対象・操作・結果 |
| 見出し、本文、ボタン、画像が理由なくすべて中央に積まれる | 内容に合う分割や大きな製品プレビュー |
| 主操作の隣に多数のボタンやbadgeが並ぶ | 主操作と副操作の優先順位を整理 |
| 無関係な球体、宇宙、ロボット、発光する脳 | 製品そのものか、説明できる一つの題材 |
| 画像へ焼き込まれた偽の文字やボタン | 本物のHTMLの文字・操作部品 |
| 意味のない画像が全セクションにある | 理解に役立つ箇所へ絞る |
| 空の画像枠や仮の製品画面を完成扱い | 必要な素材を揃えるか、未完了として報告 |

## 動き

| 兆候 | 修正の方向 |
| --- | --- |
| 実際の状態と関係ない`animate-pulse`、`animate-ping` | 静止表示 |
| `transition-all`、カードの拡大hover | 対象プロパティを指定した色や面の変化 |
| 単純なUIで過剰なspringやバウンド | 一つの落ち着いたeasing |
| すべてのカードが別方向から登場する | 必要なら一つの短い登場演出 |
| 大きなレイアウト値やぼかしが連続変化する | transformや透明度を使う適切な表現 |
| 動きを減らす設定でも移動・拡大・バウンドが続く | 静止表示や短い色・透明度の変化 |
