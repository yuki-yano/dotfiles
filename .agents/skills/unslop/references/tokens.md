# 既定値

有効なスタイル方針の出発点。ユーザーが維持・解除を指定した項目には適用しない。既存の良いシステムがあれば値を置き換えず、その使い方を整える。機能・情報の保持、日本語の可読性、アクセシビリティを優先する。

## 余白とレイアウト

- スケール: 4、8、12、16、20、24、32、40、48、64、80、96、128px。
- 操作部品の内側: 4〜12px。関連する項目間: 2〜8px。グループ間: 12〜24px。
- セクション間: 32〜64px、LPでは80〜128px。
- 行高: 高密度32px、通常36px、タッチ操作40〜44pxを出発点にする。既存の必要な密度や対象プラットフォームの操作領域を損なわない。
- サイドバー幅: 240〜280px。本文の左右余白: 24〜32px。本文上限幅: 1440〜1600px程度。
- ヘッダー高: 56〜64px。ナビゲーションの行間: 2〜4px。見出しの上24px、下8px。
- 縦積みheroのナビゲーションから見出しまで: desktop 96〜128px、mobile 48〜64px。左右分割では画像に対する縦位置で判断する。
- stat cardはdesktopで3〜4枚を出発点にする。主チャートは本文幅の2/3以上、高さ280〜360px程度。その隣の補助表示は小さなリストや表を基本にする。

## 中立色の階調

アプリとダッシュボードの表面はgraphiteか同程度に彩度の低い階調にする。LPは題材に合わせてwarmやinkを選んでよい。背景そのものが強い色に見えない範囲で調整する。

### 暗色

| 役割 | Graphite | Warm | Ink |
| --- | --- | --- | --- |
| 最も深い面・サイドバー | #0f0f10 | #12110f | #07080d |
| ページ背景 | #141415 | #161513 | #0b0d14 |
| カード | #19191b | #1c1a18 | #11141c |
| 選択行・入力などの浮いた面 | #232325 | #262421 | #1a1e28 |
| 主文字 | #ededed | #efe9de | #eef0f5 |
| 副文字 | #a1a1a6 | #aaa398 | #a3a9b8 |
| 補助文字・アイコン | #85858b | #8a847a | #7a8296 |

### 明色

| 役割 | Graphite | Warm | Ink |
| --- | --- | --- | --- |
| ページ背景 | #fafafa | #f7f4ee | #f5f7fa |
| カード | #ffffff | #fdfbf7 | #ffffff |
| 浮いた面 | #f4f4f5 | #efe9df | #eceff4 |
| 主文字 | #171717 | #1f1b16 | #111827 |
| 副文字 | #525252 | #5e554a | #4b5565 |

罫線は主文字色の6〜10%程度の透明度を出発点にする。状態や操作領域の判別に必要な境界まで薄くしない。補助文字も通常の文字として使うなら背景とのコントラスト比4.5:1以上を確認する。表の色は背景ごとに再確認し、組み合わせを無条件に合格としない。

## アクセントと状態色

- 実在するブランド色を維持する。指定がなければ題材から1色を選ぶ。
- 暖かな題材: amber、coral、ember orange。冷たい題材: cobalt、teal、sky blue。自然: moss、sage。紫〜青を理由なく毎回使わない。
- 主操作、選択状態、重要な数値など、画面の少数の箇所へ集める。チャートの系列や状態色を1色へ潰さない。
- 肯定的な状態: 暗色で#4cc38a、明色で#16a34a。否定的な状態: 暗色で#e5484d、明色で#dc2626。文字として使う場合のコントラストは別途確認する。

## ボタン

- heroは高さ44〜48px、ナビゲーションは32〜36px、左右余白16〜20pxを出発点にする。日本語ラベルが収まる幅と対象入力に必要な操作領域を確保する。
- 暗色の主ボタンは階調内の白に近い色と暗い文字、またはアクセント。明色では主文字色の面と白い文字、またはアクセント。
- 副ボタンは浮いた面、細い罫線、主文字色。
- 暗色の小さな上辺の光は`inset 0 1px 0 rgba(255,255,255,0.12)`程度。発光させない。

## 書体

和文は既存の和文フォントを優先し、未選定ならOS標準の表示を基準にする。次は欧文部分の候補であり、日本語を表示できる書体の選定を代替しない。導入済みのものから選び、この一覧のために依存を追加しない。

| 性格 | UI用の欧文候補 | 必要な場合の組み合わせ |
| --- | --- | --- |
| 正確・技術的・落ち着いた | Geist、Inter、IBM Plex Sans | 数値にGeist Mono、IBM Plex Mono、JetBrains Mono |
| 温かい・親しみやすい | Instrument Sans、DM Sans、Figtree | 欧文の大見出しだけInstrument Serif、Newsreader |
| 編集的・文学的 | Inter、Instrument Sans | 欧文見出しにNewsreader、Instrument Serif、Fraunces |
| 遊び心・力強さ | Space Grotesk、Bricolage Grotesque | 必要な数値や識別子に等幅 |

## 日本語を含む文字サイズ

次の値は和文を含むUIの出発点であり、一律の下限ではない。実際のフォント、漢字・かな、文字拡大、必要な密度で調整する。11px以下へ縮小して内容を押し込まない。

| 用途 | サイズ | 行間 | 太さ |
| --- | --- | --- | --- |
| 短い補助表示・件数 | 12〜13px | 1.4〜1.6 | 400〜500 |
| 説明・caption | 13〜14px | 1.5〜1.7 | 400 |
| 本文 | 14〜16px | 1.5〜1.8 | 400〜500 |
| ナビゲーション・操作ラベル | 14〜15px | 1.4〜1.6 | 400〜500 |
| ページ見出し | 28〜36px | 1.25〜1.4 | 400〜500 |
| hero見出し | desktop 48〜64px、mobile 32〜40px | 1.2〜1.4 | 400〜500 |
| 大きな数値 | 28〜32px | 1〜1.2 | 500、桁揃え |

太さは400と500を中心にし、まれな強調だけ600。可読性が不足する場合は適切に調整する。和文の字間は0を基準にし、欧文の大見出し向けの負の字間を継承させない。小さい文字にも負の字間を使わない。

## 角丸とアイコン

- キー表示・小さなtag: 4〜6px。行・入力・ボタン: 8〜10px。カード: 12〜16px。panel・window: 14〜20px。
- 内側の角丸は「外側の角丸−間隔」を出発点にし、通常4px未満にしない。狭い入れ子などで不自然なら実際の形状を優先する。
- アイコンは既存の一つのセットを使う。16pxまたは18px、線幅1.5、ラベルまで8〜10pxを出発点にし、和文の見え方に合わせて光学調整する。

## 奥行きと動き

- 暗色は面の段階と細い罫線で奥行きを作る。
- 明色の小さな影: `0 1px 2px rgba(0,0,0,0.05)`。浮いた面: `0 8px 24px rgba(0,0,0,0.06)`。
- easingは`cubic-bezier(0.22, 1, 0.36, 1)`を出発点にする。
- hover・press・toggle: 120〜180ms。menu・popover・tooltip: 160〜220ms。登場・sheet: 300〜500ms。
- 必要な登場移動: 6〜12px。pressのscale: 0.97〜0.98。stagger: 40〜60ms、最大6要素程度。
- 動きを減らす設定では移動・拡大・staggerを抑え、状態が伝わる表示にする。通常時の値をそのまま適用しない。
