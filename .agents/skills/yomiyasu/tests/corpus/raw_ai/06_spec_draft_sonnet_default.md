# Webhook受信 リトライ制御・DLQ機能仕様（ドラフト）

## 概要
決済プロバイダからのWebhook通知を受信し、処理に失敗した通知を再試行する。上限回数を超えた通知はDLQへ移し、手動で再処理できるようにする。

## 受信
署名を検証して通知をキューに保存し、すぐにHTTP 200を返す。処理は非同期ワーカーが担当する。イベントIDを冪等キーとし、同じ通知を二重に処理しない。

## リトライ
タイムアウト、5xx、DB接続断などの一時的エラーのみ再試行する。間隔は指数バックオフ（初回30秒、倍率2、上限1時間）とし、±20%のジッタを加える。最大8回まで実行する。署名不正やスキーマ不正などの恒久的エラーは再試行せず、ただちにDLQへ送る。

## DLQ
再試行上限を超えた通知と恒久的エラーの通知は、元のペイロード、エラー内容、試行履歴とあわせて30日間保持する。DLQの件数が10件を超えたら運用チームへ通知する。管理画面から個別または一括で再投入できる。
