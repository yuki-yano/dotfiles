# 障害報告書

**件名：** 高負荷時のデータベースコネクションプール枯渇によるAPI 504エラーの発生

## 1. 概要
YYYY年MM月DD日 HH:MM から HH:MM までの間、APIが504エラーを返却した。一部の利用者がサービスを利用できない状態が続いた。

## 2. 原因
アクセス集中により同時リクエスト数が増加し、データベースのコネクションプールが枯渇した。実行時間の長いクエリが接続を長く占有していたため、後続のリクエストは接続の取得を待つうちにタイムアウトした。

## 3. 対応
接続上限を一時的に引き上げ、アプリケーションを再起動して復旧した。復旧後はエラー率と応答時間を監視し、正常値に戻ったことを確認した。

## 4. 再発防止策
1. プールサイズと接続取得タイムアウトを、負荷実績に基づいて見直す。
2. 低速クエリを改善し、必要なインデックスを追加する。
3. 接続使用率を監視し、閾値を超えた時点で通知する。
4. 負荷試験を定期的に実施し、オートスケールを導入する。
