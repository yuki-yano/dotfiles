# 大賀愛一郎 実務エッセイ 抜粋 6

渡した話① 社内ドキュメントを、LLMから引ける状態にする
最初にやったのは、社内のドキュメントをLLMから直接引ける状態にすることです。




Notion MCP を使って、Notion にある資料を Claude Desktop や Codex App から参照できるようにしました。（語るほどでもない非常にシンプルな構成です。）



社内のドキュメントは、書いた人にとっては自明な前提が省かれていることが多いです。


しかもそれが複数のページに散らばっていて、どれが最新かも分からないです。
そこを横断して「この話はこことここに書いてあります！」と出典つきで返してくれるだけで、オンボーディングの速度はまったく変わりました。
……が、続けていくうちに、大きな問題に気づきます。
