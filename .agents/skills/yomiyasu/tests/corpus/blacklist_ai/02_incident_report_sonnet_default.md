# 障害報告書

**件名** 高負荷時のDBコネクションプール枯渇によるAPI 504エラー

**発生日時** 2026年9月28日 14:05〜14:42（約37分）

**影響** 注文APIと会員情報APIで、全リクエストの約35%が504エラーになった。

## 経緯
キャンペーン開始で、リクエスト数が通常の約3倍に増えた。プール上限は20接続だった。重い集計クエリが接続を長く占有し、待機中のリクエストが30秒のタイムアウトに達して504を返した。

## 原因
- プール上限がピーク時の同時接続数より小さかった。
- 集計クエリに実行時間の上限がなかった。
- 負荷試験でキャンペーン規模の流量を検証していなかった。

## 対応
集計バッチを停止し、プール上限を50に引き上げてアプリケーションを再起動した。14:42に正常化を確認した。

## 再発防止策
1. クエリの実行時間に上限を設定する。
2. 集計処理を読み取りレプリカへ移す。
3. プール使用率が80%を超えたら通知する。
4. キャンペーン前の負荷試験を必須にする。
