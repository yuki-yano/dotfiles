# 障害報告書：DBコネクションプール枯渇によるAPI 504エラー

**発生日時**：2026年9月24日 20:12〜20:47（35分間）
**影響**：注文APIとユーザー情報APIのリクエストの約38%が504を返した。

**原因**
キャンペーン通知の配信で、同時アクセスが平常時の4倍になった。APIサーバー1台あたりのコネクションプール上限は20本だった。在庫集計クエリの実行時間が2秒を超え、コネクションを保持したまま待つリクエストが積み上がった。プールが埋まったため、後続のリクエストは取得待ちのまま30秒のタイムアウトに達し、ゲートウェイが504を返した。

**対応**
20:30にオンコール担当が原因を特定し、集計クエリを呼ぶエンドポイントを一時停止した。続いてプール上限を40本に引き上げ、20:47に復旧を確認した。

**再発防止**
- 集計クエリを読み取りレプリカへ移す
- プール取得待ちのタイムアウトを3秒に短縮する
- プール使用率80%で通知するアラートを追加する
