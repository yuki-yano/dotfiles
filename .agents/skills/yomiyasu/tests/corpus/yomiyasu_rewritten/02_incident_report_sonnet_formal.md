# 障害報告書

件名は、高負荷時にデータベースのコネクションプールの空きがなくなり、APIが504エラーを返した件である。

## 1. 概要
YYYY年MM月DD日HH:MMからHH:MMまで、APIが504エラーを返した。この間、一部の利用者がサービスを利用できなかった。

## 2. 原因
アクセスが集中して同時リクエスト数が増え、データベースのコネクションプールの接続をすべて使い切った。実行時間の長いクエリが接続を保持し続けたため、後続のリクエストは接続の空きを待つ間にタイムアウトした。

## 3. 対応
システム管理者が接続上限を一時的に引き上げ、アプリケーションを再起動して復旧させた。復旧後はエラー率と応答時間を監視し、正常値に戻ったことを確認した。

## 4. 再発防止策
開発者は、負荷の実績に基づいてプールサイズと接続取得のタイムアウトを見直す。あわせて低速なクエリを改善し、必要なインデックスを追加する。システム管理者は接続使用率を監視し、閾値を超えた時点で通知が届くように設定する。さらに負荷試験を定期的に実施し、オートスケールを導入する。
