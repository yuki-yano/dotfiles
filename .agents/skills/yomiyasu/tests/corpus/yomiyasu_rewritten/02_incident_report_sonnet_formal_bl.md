# 障害報告書

件名　データベースコネクションプールが枯渇し、APIが504エラーを返した

発生日時　ピーク時間帯に高負荷が続いた期間

影響範囲　API全般。一部のリクエストがタイムアウトし、ゲートウェイが504 Gateway Timeoutを返した。

## 事象

アクセスが集中して同時リクエスト数が増え、アプリケーションが保持するデータベース接続数がコネクションプールの上限に達した。後続のリクエストは接続を取得できないまま待たされ、ゲートウェイのタイムアウト閾値を超えて504エラーになった。

## 原因

直接の原因は、想定したピーク負荷に対してコネクションプールの最大接続数が少なすぎたことである。さらに、一部の長時間実行クエリが接続を長く保持し続け、接続が解放されにくくなったため、プールの枯渇が早まった。運用チームはプール使用率の監視と警報を設定していなかったため、障害の検知も遅れた。

## 対応

運用担当者がアプリケーションを再起動して接続を解放し、プールの最大接続数を暫定的に増やして復旧させた。

## 再発防止策

開発チームは負荷試験の結果をもとにプールサイズを見直し、データベース側の最大接続数と矛盾しないか確認する。長時間実行クエリは最適化し、クエリと接続取得のそれぞれに適切なタイムアウトを設定する。運用チームはプール使用率と接続の待ち時間を監視し、閾値を超えたときに警報が発報されるようにする。
