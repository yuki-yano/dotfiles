# 障害報告書 DBコネクションプールの枯渇によるAPIの504エラー

2026年9月24日20:12から20:47までの35分間、注文APIとユーザー情報APIへのリクエストの約38%に対してゲートウェイが504を返した。

## 原因

キャンペーン通知を配信したところ、同時アクセスが平常時の4倍に増えた。APIサーバー1台あたりのコネクションプール上限は20本だった。在庫集計クエリが2秒以上かかり、コネクションを保持したまま待つリクエストが増え続けた。20本すべてが使用中になったため、後続のリクエストはコネクションの取得を待ち続け、30秒のタイムアウトに達した。ゲートウェイはこれらのリクエストに504を返した。

## 対応

20:30にオンコール担当が原因を特定し、集計クエリを呼ぶエンドポイントを一時停止した。続いてプール上限を40本に引き上げ、20:47に復旧を確認した。

## 再発防止

開発チームは集計クエリを読み取りレプリカへ移し、プール取得待ちのタイムアウトを3秒に短縮する。あわせて、プール使用率が80%に達したら通知するアラートを追加する。
