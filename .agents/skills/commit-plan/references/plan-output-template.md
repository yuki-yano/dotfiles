# コミット計画のテンプレート

複雑な分割や、実行前に計画書を確認したい依頼で使う。
単純なcommit依頼の進捗報告では、目的と対象を短く示すだけでよい。

```markdown
## 対象

- 対象範囲: <全体 / pathspec>
- 実行意図: <計画のみ / 実行指示あり / 承認待ち>
- 対象外差分: <pathと扱い。なければ省略>

## コミット内訳

1. <type>: <目的>
   対象: <files>。<部分stageが必要な場合はその範囲>

## DoD

機能完了条件:
- [ ] 各コミットに指定した目的の差分だけが含まれる。

テスト完了条件:
- [ ] staged diffと計画が一致し、必要な検証が成功している。

運用反映条件:
- [ ] <計画のみなら計画提示、実行依頼なら全コミットのhashと残差分報告>が完了している。
```

計画のみの依頼では、実行確認を出さずに終了する。
明示的なcommit指示または承認済み計画がある場合は、停止条件がなければそのまま実行する。
それ以外は、計画を提示してからcommit実行の承認を受ける。確認の入力形式は固定しない。
