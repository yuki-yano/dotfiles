# Argon Rewrite

指定した文章をArgon Highへ渡し、情報を保ちながら分かりやすい日本語へ書き直す。本文と添えた背景はGoogleへ送信される。

1. 対象本文を確定する。指定がなければ直前の自分の対象本文を使い、特定できなければ確認する。ファイルは指定されたものだけ読み、フォルダから推測しない。表示中の文字列を逐次傍受せず、一度に渡す。
2. 会話から分かる読み手・目的・必要な背景だけを`context`に添える。全会話履歴は送らない。
3. `scripts/rewrite.py`へ、標準入力でUTF-8 JSONを渡す。必須の`text`と任意の`context`はいずれも文字列。入力経路によらず同じスクリプトを使う。

   ```bash
   python3 ~/.agents/skills/argon-rewrite/scripts/rewrite.py <<'JSON'
   {"text":"承認前には公開しません。費用は未確認です。","context":"読み手は担当者。作業状況を伝える回答下書き。"}
   JSON
   ```

4. 原文と結果を照合する。主張・数値・固有名詞・否定・条件・例外・担当・時制、断定や義務等の強さ、不確実性、引用と帰属、URLとリンク先、コード・コマンド・識別子・frontmatterを確認する。Markdownの見出しが変わった場合は内部リンクも確認する。欠落・改変やツール操作があれば採用せず、理由を報告する。
5. 問題がなければ、Argonの文体を自分の文体へ直し直さず、本文を返す。ファイル保存・上書きは依頼された場合だけ親Agentが行う。

書き直しの指示は[専用Agentテンプレート](assets/argon-rewrite.md)、モデル指定はスクリプトを正とする。情報を削って短くすることを目的にせず、専門語や曖昧さを推測で確定しない。全回答への常時適用、会話継続、他モデルへのfallbackは行わない。

スクリプトは呼び出しごとに一時workspaceを作り、セッション限定のstrict設定で実行する。終了コード0・最終SUCCESS・非空の本文を検証し、途中出力やツールstepを含む結果は返さない。待機上限は10分。診断は標準エラーに出る。

一時cwdは完全な隔離ではない。global rules・hooks・MCP・plugin等の影響は残り得る。`init`のモデル・Agent・cwd・権限とツール一覧、およびtool stepを点検する。agy 1.4.12の`init.tools`は専用Agentの`tools: []`でも一覧を含むため、空配列だけを実行制限の証拠にしない。確認範囲と制限は[検証記録](references/verification.md)を参照する。
